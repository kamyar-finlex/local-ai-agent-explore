# The entire reachable internet, one host per line. Exact matches only --
# a leading dot would mean "any subdomain", which is not an allowlist.
#
# Determined empirically (see EGRESS.md); every entry says what needs it.
#
# The workflow tracks work as GitHub issues (see ORCHESTRATOR.md), so both the
# orchestrator and the workers talk to GitHub and nothing else. `api.linear.app`
# was here while Linear was the issue tracker and has been removed: an allowlist
# entry that nothing needs is a write channel left open for no reason.

# planner + dispatcher: read and write issues and labels (REST + GraphQL, i.e.
# the `gh` CLI). workers: open a pull request.
api.github.com

# workers: all of git over smart HTTPS -- clone, fetch, ls-remote AND push.
# Measured: packfiles are served by github.com itself, so a push needs this host
# and nothing else.
github.com

# Deliberately NOT here, each of which will fail loudly if it turns out to be
# needed, which is the point:
#   codeload.github.com          - tarball/zip fetch only. Nothing in this
#                                  workflow downloads archives; clone and push
#                                  do not touch it.
#   objects.githubusercontent.com - release assets and raw content.
#   github-cloud.s3.amazonaws.com - Git LFS. An S3 bucket host is a wide-open
#                                  write channel; add it only knowingly.
#   npm / PyPI / RubyGems         - bake dependencies into the worker image
#                                  instead of widening this file.

# workers: installing the target project's declared dependencies.
#
# Added deliberately, and it is the widest hole in this allowlist. Everything
# else here is a specific service we control or review; PyPI is a public index
# from which a worker can fetch and EXECUTE arbitrary third-party code. A
# typosquatted or compromised package runs inside the worker with its token.
#
# The narrower alternatives, for the record: bake the project's dependencies
# into the worker image at BUILD time, outside the sandbox, so nothing is
# fetched at run time; or pin a hash-locked manifest and install with
# --require-hashes. Both were passed over here because the planner chooses the
# stack after the image is built, which makes a per-project image the real
# answer rather than a quick one.
pypi.org
files.pythonhosted.org
