# The entire reachable internet, one host per line. Exact matches only --
# a leading dot would mean "any subdomain", which is not an allowlist.
#
# Determined empirically (see EGRESS.md); every entry says what needs it.
#
# The workflow tracks work as GitHub issues (see ORCHESTRATOR.md), so both the
# orchestrator and the workers talk to GitHub and nothing else. `api.linear.app`
# was here while Linear was the issue tracker and has been removed: an allowlist
# entry that nothing needs is a write channel left open for no reason.

# planner + dispatcher: read and write issues and labels (REST + GraphQL, i.e.
# the `gh` CLI). workers: open a pull request.
api.github.com

# workers: all of git over smart HTTPS -- clone, fetch, ls-remote AND push.
# Measured: packfiles are served by github.com itself, so a push needs this host
# and nothing else.
github.com
